🛍️ Contoso Sales Performance Dashboard

 Project Title / Headline

📊 Contoso Sales Performance & Profitability Analysis Dashboard

An interactive Power BI dashboard designed to analyze sales performance, profitability trends, product performance, and geographical sales distribution for the Contoso retail business.


1. Short Description / Purpose

The Contoso Sales Dashboard is a dynamic Power BI report built to monitor overall business performance using sales, profit, discount, and return metrics. The dashboard helps stakeholders track profitability trends, evaluate brand performance, analyze regional sales distribution, and support data-driven business decisions.


2. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 Power BI Desktop – Used for dashboard creation, report designing, and data visualization.
* 📂 Power Query – Used for data cleaning, transformation, handling missing values, and formatting.
* 🧠 DAX (Data Analysis Expressions) – Used for creating KPIs, calculated measures, running totals, YoY calculations, and profitability metrics.
* 📝 Data Modeling – Built relationships between tables for efficient filtering and analysis.
* 📁 File Formats – `.pbix` for Power BI report and `.png` for dashboard preview screenshots.


3. Data Source

📌 Dataset Name: Contoso Sales Dataset
📌 Source Type: Retail Sales & Product Transaction Dataset

The dataset contains detailed business transaction data including:

* Sales Quantity
* Discount Quantity
* Net Quantity
* Sales Amount
* Discount Amount
* Return Amount
* Cost of Goods Sold
* Net Profit
* Product Category
* Brand Name
* Store Details
* Country & Region Information
* Order Count
* Date Hierarchy (Year, Quarter, Month)

The dataset enables analysis of profitability, sales growth, regional performance, and product contribution across multiple business dimensions.


4. Features / Highlights

 Business Problem

Retail businesses generate massive amounts of transactional data daily. Without proper visualization and analysis, it becomes difficult to answer important business questions such as:

* Which regions and countries generate the highest profit?
* How is net profit changing over time?
* Which brands contribute the most to yearly profit growth?
* How do discounts and returns impact profitability?
* Which stores perform best across different regions?
* What are the overall sales and operational trends?


 🎯 Goal of the Dashboard

The dashboard was created to provide a centralized and interactive reporting solution that helps stakeholders:

* Monitor sales and profitability KPIs
* Track profit trends over time
* Analyze regional and store-level performance
* Identify high-performing brands
* Evaluate the impact of discounts and returns
* Support strategic business decision-making


📊 Walkthrough of Key Visuals

1. KPI Cards (Top Section)

The dashboard contains key business indicators such as:

* 📦 Sales Quantity
* 🎯 Discount Quantity
* 📈 Net Quantity
* 💰 Sales Amount
* 💸 Discount Amount
* ↩️ Return Amount
* 🏷️ Cost of Goods Sold
* 🟢 Net Profit

These KPIs provide a quick overview of overall business performance.


2. Slicers Panel (Left Side)

Interactive slicers allow users to dynamically filter the entire dashboard by:

* Year
* Channel
* Region / Country
* State / Province
* City
* Store
* Product Category
* Product Subcategory

This improves dashboard interactivity and enables detailed analysis.


3. Net Profit Running Total by Date Hierarchy (Combo Chart)

 Displays running net profit trends over months, quarters, and years.

 Insights:

* Tracks business growth patterns over time
* Highlights periods of profit decline or growth
* Helps identify seasonal business trends


4. Net Profit Running Total by Quarter (Bar Chart)

 Shows cumulative net profit progression across quarters.

 Insights:

* Helps compare yearly quarter-wise business growth
* Useful for executive-level financial monitoring


5. Year Over Year Net Profit by Brand (Waterfall Chart)

 Visualizes profit contribution by different brands.

Insights:

* Identifies brands driving profitability growth
* Shows positive and negative profit contributors
* Helps businesses focus on high-performing product lines


6. Geography and Store Details (Table Visualization)

 Displays detailed region-wise and store-level performance metrics.

Includes:

* Total Sales
* Net Quantity
* Total Expense Cost
* Net Profit
* Average Order Amount
* YoY Net Profit %
* YoY Net Profit %
* Order Count

Insights:

* Helps identify top-performing countries and stores
* Useful for regional expansion and operational decisions

7.  How to Use the Dashboard

1. Open the `.pbix` file using Power BI Desktop.
2. Use slicers on the left panel to filter data dynamically.
3. Analyze KPI cards for quick business summaries.
4. Explore profit trends using charts and waterfall visuals.
5. Review geographical and store-level performance in the table section.
6. Interact with visuals for deeper insights and drill-down analysis.
